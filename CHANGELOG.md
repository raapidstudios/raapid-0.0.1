# Changelog

## 0.0.1 — Initial public release

- Introduces the Raapid command-line interface: `raapid run <file.raap>`.
- Compiles Raapid source to LLVM IR and executes it with an in-process JIT.
- Supports source-file imports and built-in `random`, `time`, and `date` modules.
- Includes sample programs for basic execution and module smoke testing.

This is an experimental first release. Expect breaking changes.
